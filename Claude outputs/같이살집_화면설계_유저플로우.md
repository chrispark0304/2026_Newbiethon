# 같이살집 — 화면설계 & 유저플로우

## 한 줄 컨셉
두 사람이 각자 조건(직장 위치·예산·평수)을 입력하면, 지도 위에서 매물을 살펴보고, 매물 하나를 골라 그 집에서 각자 직장까지 가는 지하철 경로까지 한 화면에서 확인하는 3단계 플로우.

---

## 전체 유저플로우

```
[화면 1] 조건 입력
     │  "같이 살자" 버튼 클릭
     ▼
[화면 2] 지도 + 매물 목록
     │  매물(지도 마커 또는 왼쪽 리스트 카드) 클릭
     ▼
[화면 3] 매물 상세 + 통근 경로
```

---

## 화면 1. 조건 입력

**목적**: 함께 살 두 사람의 조건을 각각 받는다.

**레이아웃**: 화면을 좌우 반반으로 나눠 사람1 / 사람2 카드를 나란히 배치.

각 카드에 들어가는 요소 (두 사람 동일 구성):
- 직장 위치 검색창 (아이콘 + 텍스트 입력, 장소 자동완성)
- 가격 범위 슬라이더 (최소~최대, 투 핸들)
- 면적 범위 슬라이더 (최소~최대, 투 핸들)

하단 중앙: **"같이 살자"** 버튼 — 눈에 띄게 큼직한 스타일 (사람들이 헷갈리지 않고 바로 누르도록 강조)

**인터랙션**: 버튼 클릭 → 두 사람의 입력값으로 매물 검색을 실행하고 화면 2로 이동.

---

## 화면 2. 지도 + 매물 목록

**목적**: 검색된 매물들을 지도 위 위치 감각과 함께 훑어본다.

**레이아웃**: 좌측 = 매물 리스트(세로 스크롤), 우측 = 지도.

**왼쪽 매물 리스트 (카드형)**
각 카드에 표시할 정보:
- 집 아이콘
- 월세 (예: 51만원)
- 동네/주소
- 층수 · 전용면적(평수)

**오른쪽 지도**
- 두 사람의 직장 위치를 마커로 표시 (회사 아이콘, 사람별로 구분되는 색/아이콘)
- 매물들을 마커로 표시 — 이 단계에서는 **가격·평수만** 간단히 보여줌 (상세정보는 다음 화면에서)

**인터랙션**: 지도의 매물 마커(또는 왼쪽 리스트의 카드)를 클릭하면 → 화면 3으로 이동, 해당 매물이 선택된 상태로 전환.

---

## 화면 3. 매물 상세 + 통근 경로

**목적**: 고른 매물 하나에 집중해서, "이 집에 살면 각자 출근길이 어떻게 되는지"까지 한눈에 보여준다.

**레이아웃**: 좌측 = 집 상세 정보, 우측 = 통근 경로 지도.

**왼쪽 집 정보**
- 집 아이콘 + 매물 상세 (가격, 전용면적, 층, 건축년도 등 — 데이터 담당이 수집한 실거래가 컬럼에 맞춰 채움)

**오른쪽 경로**
- 이 집 위치를 중심으로, 각자의 직장까지 가는 **지하철 노선 경로**를 색을 구분해서 표시
  - 예: 사람1 경로 = 빨간선, 사람2 경로 = 주황/초록선
- 환승역 등 경유 지점도 표시

**인터랙션**: 뒤로가기 → 화면 2(지도+목록)로 복귀, 다른 매물도 이어서 비교 가능.

---

## 화면 간 공통 규칙
- 사람1 / 사람2를 나타내는 색상은 화면 전체에서 일관되게 유지 (예: 사람1 = 초록 계열, 사람2 = 보라 계열 — 기존 프로토타입의 `--me` / `--friend` 컬러 변수와 맞추면 통일감 있음)
- 지도의 "직장 마커"와 "매물 마커"는 아이콘 형태로 구분되어야 헷갈리지 않음

---

## (선택) 나중에 붙일 수 있는 확장
지금 화면설계엔 없지만, 이전에 팀에서 얘기했던 요소들을 화면 3에 자연스럽게 얹을 수 있음:
- 공동 적합도 점수 (조화평균/페널티 기반) 를 집 상세 옆에 배지로 표시
- 방 배정 + 월세 분담 추천을 집 정보 섹션에 추가

---

## 팀 공유용 요약 프롬프트 (복붙용)

> "같이살집" 서비스는 3단계 화면으로 구성됨.
> 1) 첫 화면 — 두 사람 각각 직장 위치 검색 + 가격범위 슬라이더 + 면적범위 슬라이더 입력 카드를 좌우로 배치, 하단에 큰 "같이 살자" 버튼.
> 2) 버튼 클릭 시 지도 화면으로 이동 — 왼쪽엔 매물 리스트(가격·평수·동네 카드), 오른쪽 지도엔 두 사람의 직장 위치 마커와 매물 마커(가격·평수만 표시)를 함께 띄움.
> 3) 매물 마커나 리스트 카드를 클릭하면 상세 화면으로 이동 — 왼쪽엔 그 매물의 상세 정보, 오른쪽엔 그 집에서 각자 직장까지 가는 지하철 경로를 사람별 색으로 구분해서 보여줌.
