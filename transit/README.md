# transit — 대중교통 통근시간 엔진

집 후보군과 직장 좌표를 받아 **대중교통 통근시간(분)** 을 계산한다.
외부 길찾기 API를 호출하지 않는다. 공개 데이터로 그래프를 직접 만들어 다익스트라를 돌린다.

- **수도권 전철 23개 노선 652개역** · API 호출 0회 · 쿼터 없음 · 런타임 의존성 없음
- 직장 1곳당 다익스트라 **1회**면 후보 전부가 해결된다 — 652개역 전수 추천이 **4ms**
- 버스를 나중에 얹어도 그래프·라우터 코드는 **그대로** — 자세한 건 [SCHEMA.md](SCHEMA.md)

## 빠른 시작

```bash
python -m transit.cli build                      # 원본 → 피드 (평소 재실행 불필요)

# 직장 좌표만으로 살 만한 역 찾기
python -m transit.cli recommend \
  --work "재윤:37.4979,127.0276" \
  --work "친구:37.5216,126.9243" \
  --limit 30

python -m transit.cli query \
  --work 37.4979,127.0276 --home 37.5571,126.9245

python -m transit.cli matrix \
  --work "강남:37.4979,127.0276" \
  --work "여의도:37.5216,126.9243" \
  --homes transit/data/manual/homes.sample.csv
```

```
역                  재윤     친구    최대     합    격차  노선
신반포                15     17    17    32     2  9호선
동작                 20     16    20    36     4  4호선·9호선
사평                 11     21    21    32    10  9호선
```

`recommend --json`이 프로토타입에 물릴 지점이다(좌표·노선·직장별 통근시간이 그대로 나온다).
집 후보가 이미 정해져 있다면 `matrix`로 표만 뽑으면 된다.

### 무엇을 "최적"으로 볼 것인가

두 사람의 통근시간은 **서로 상충한다.** A 직장에 가까워지면 B는 대개 멀어진다.
그래서 정답이 하나가 아니고, `--objective`로 무엇을 중시할지 고른다.

| 값 | 뜻 | 위 예시의 1위 |
|---|---|---|
| `minimax` (기본) | 더 오래 걸리는 쪽을 줄인다 — 형평성 | 신반포 (15/17) |
| `total` | 둘의 합을 줄인다 | 강남 (0/29) — 한쪽이 0이면 합이 최소라 편중된다 |
| `fair` | 둘의 격차를 줄인다 | 숭실대입구 (25/25) |

`--pareto`는 **어느 쪽도 손해 보지 않고는 개선할 수 없는** 후보만 남긴다.
취향을 묻지 않고 선택지를 좁히는 방법이라, 위 예시에서는 652개 역이 11개로 줄어든다.

```
$ python -m transit.cli recommend --work A:... --work B:... --pareto --spread 0
강남 (0,29) → 교대 (6,27) → 신논현 (7,23) → 사평 (11,21) → 신반포 (15,17)
  → 구반포 (17,16) → 흑석 (21,11) → 노들 (23,9) → 노량진 (25,7) → 샛강 (27,5) → 여의도 (29,0)
```

두 직장을 잇는 9호선 축이 그대로 나온다. 이 11개 밖은 볼 필요가 없다.

## 구조

```
원본 CSV ─► feeds/*.py ─► data/feed/*.csv ─► graph.py ─► router.py
           (수단별 파서)    (정규화 피드)       (CSR)      (역방향 다익스트라)
                                  ▲
                          버스는 여기에 합류한다
```

| 파일 | 역할 |
|---|---|
| `fetch.py` | 원본 다운로드 (평소 불필요 — 원본을 커밋해 둠) |
| `textio.py` | CP949/UTF-8 인코딩 방어 |
| `overrides.py` | 손으로 덮어쓴 좌표 보정값 로더 |
| `feeds/rail.py` | 수도권 전철 전 노선. OSM 토폴로지 + 실측/추정 소요시간 |
| `feeds/measured.py` | 서울교통공사 실측 구간 소요시간 조회표 |
| `feeds/transfer_times.py` | 환승역 통로 도보시간 실측 → 역·노선별 허브값으로 분해 |
| `feeds/bus.py` | **버스 스텁** — 필요한 데이터셋과 함정을 주석에 정리해 둠 |
| `build_feed.py` | 피드 병합 + 도보 환승 엣지 자동 생성 |
| `graph.py` | CSR 그래프 (정·역방향) |
| `router.py` | 통근시간 계산 + 경로 설명 |
| `recommend.py` | 직장 좌표 → 후보 역 전수 탐색 + 다목적 정렬/파레토 |
| `calibrate.py` | ODsay 실측과 비교해 오차 측정 |

> **인코딩**: 서울 열린데이터광장 CSV는 CP949로 내려온다.

## 현재 범위와 한계

수도권 전철 **23개 노선 652개역**을 커버한다.
1~9호선 · 경의중앙 · 수인분당 · 경춘 · 경강 · 서해 · 신분당 · 공항철도 ·
인천1·2 · 우이신설 · 신림 · 김포골드 · 용인에버라인 · 의정부경전철 · GTX-A.

**꼭 알고 쓸 것:**

1. **구간 소요시간의 36%만 실측이다.** 서울교통공사 실측(OA-12034)은 자사 운영 구간뿐이라
   1호선 서울역 이남(코레일 경부·경인선), 9호선, 신분당선 등은 실측값이 없다.
   나머지 64%는 실측 271개 구간에 적합한 회귀식
   `소요시간(초) = 23.9 + 0.06324 × 선로거리(m)` (순항 57km/h, 잔차 MAE 11초)으로 추정한다.
2. **환승 통로 실측은 서울교통공사 환승역만.** 72개역 206개 (역·노선) 조합에 적용된다.
   김포공항 9호선↔공항철도처럼 타 운영사 환승역은 기본 페널티만 물린다(실제보다 싸게 나온다).
3. **급행·특급 제외.** 완행 기준이다. 실제로 급행을 타면 더 빠를 수 있다.
4. **버스 미포함.** `feeds/bus.py` 참조.
5. **배차간격 기반.** 시각표를 쓰지 않으므로 첫차·막차·정시성을 반영하지 않는다.
   출근시간대(07~09시) 평균 통근시간 **비교**가 목적이다.
   분기 노선(1호선 인천행/신창행 등)도 노선 단위 배차를 쓰므로 특정 지선 대기시간은 과소평가된다.
6. **정확도는 아직 실측 검증되지 않았다.** 표본 11건을 눈대중 참고값과 비교했을 때
   평균편차 +0.8분 / 평균절대오차 1.5분이 나왔지만, **참고값이 실측이 아니고 표본도 11건뿐이다.**
   `BOARD_PENALTY_SEC`와 `DWELL_SEC`를 그 표본에 맞춰 잡았으므로 과적합 가능성이 있다.
   실제 오차는 `calibrate.py`로 ODsay와 비교해 확인할 것.
7. **6호선 응암순환**은 단선순환이라 역방향이 실제와 다르다(근사).

## 보정

```bash
export ODSAY_API_KEY=...
python -m transit.calibrate --work 37.4979,127.0276 --homes transit/data/manual/homes.sample.csv
```

ODsay 실측과 비교해 평균절대오차와 `BOARD_PENALTY_SEC` 제안값을 뱉는다.
ODsay 무료 쿼터가 하루 30회라 기본 상한도 30으로 잡혀 있다.
**경로 탐색에는 ODsay를 쓰지 않는다. 검증 전용이다.**

## 튜닝

`config.py` 한 곳에 모여 있다.

| 파라미터 | 기본값 | 의미 |
|---|---|---|
| `WALK_SPEED_MPS` | 1.11 (4km/h) | 도보 속도 |
| `WALK_DETOUR_FACTOR` | 1.30 | 직선거리 → 실보행거리 보정 |
| `MAX_ACCESS_WALK_M` | 900 | 집/직장 ↔ 정류장 최대 도보 |
| `MAX_TRANSFER_WALK_M` | 400 | 정류장 간 도보 환승 반경 |
| `BOARD_PENALTY_SEC` | 50 | 개찰 통과 등 고정 오버헤드. 환승 통로는 별도(실측) |
| `DWELL_SEC` | 25 | 역당 정차시간. 원본 소요시간은 순수 주행시간이라 따로 더해 준다 |
